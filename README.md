# 🏠 WebApp คำนวณค่าคอมมิชชั่นอสังหาริมทรัพย์ (Pastel Edition)

เว็บแอปพลิเคชันสำหรับคำนวณส่วนแบ่งค่าคอมมิชชั่นอสังหาริมทรัพย์ ออกแบบในธีมสีพาสเทล (Pastel Theme) เรียบหรู ใช้งานง่าย รองรับการคำนวณแบบ Real-time ทั้งคำนวณจากราคาบ้านและคำนวณย้อนกลับจากเป้าหมายค่าคอมของพนักงาน

---

## ✨ ฟีเจอร์หลัก (Features)

1. **⚙️ ตั้งค่าอัตราส่วนแบ่ง (%)**:
   - ปรับอัตราค่าคอมมิชชั่นบริษัท (ค่าเริ่มต้น `3%`)
   - ปรับส่วนแบ่งพนักงานขาย (ค่าเริ่มต้น `7%` ของก้อนค่าคอมบริษัท)
   - แสดงสูตรคำนวณอัตโนมัติ: `3% × 7% = 0.21%` จากราคาบ้าน
   - บันทึกการตั้งค่าลง LocalStorage อัตโนมัติ (เปิดมาครั้งต่อไปไม่ต้องตั้งค่าใหม่)
2. **🏡 คำนวณจากราคาบ้าน (Forward Calculation)**:
   - ช่องราคาบ้านเริ่มต้นเว้นว่างไว้ (Blank) เพื่อให้กรอกง่าย
   - รองรับการจัดฟอร์แมตตัวเลขลูกน้ำ (Comma) อัตโนมัติ
   - มีปุ่มลัด (Quick Chips) 1M, 2M, 3M, 5M, 10M
   - แสดงยอด: บริษัทได้ค่าคอม, พนักงานขายได้, และบริษัทได้รับสุทธิ
3. **🎯 คำนวณย้อนกลับจากเป้าหมาย (Reverse Calculation)**:
   - กรอกเป้าหมายค่าคอมที่พนักงานต้องการ
   - คำนวณยอดขายบ้านที่ต้องทำให้ได้ และยอดค่าคอมมิชชั่นที่บริษัทจะได้รับ
4. **📊 แผนภูมิวงกลมสัดส่วน (Pastel Donut Chart)**:
   - แสดงสัดส่วนเปอร์เซ็นต์ระหว่างบริษัทและพนักงานขายอย่างชัดเจน
5. **📋 เครื่องมือเสริม**:
   - ปุ่มคัดลอกสรุปผลลัพธ์ลง Clipboard เพื่อส่ง Line / Email
   - ปุ่มพิมพ์สรุปหรือบันทึกเป็น PDF (Print Friendly)

## 🚀 วิธีการเปิดใช้งานบนเครื่อง (Local)

ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่าน Google Chrome, Safari, หรือ Edge ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์ใด ๆ

---

## 🐙 วิธีการนำขึ้น GitHub ด้วย GitHub Desktop และเปิดใช้งาน GitHub Pages

### ขั้นตอนที่ 1: เพิ่มโปรเจกต์ลงใน GitHub Desktop
1. เปิดโปรแกรม **GitHub Desktop**
2. ไปที่เมนู **File** $\rightarrow$ **Add Local Repository...** (หรือกด `Ctrl+O` / `Cmd+O`)
3. กดปุ่ม **Choose...** แล้วเลือกโฟลเดอร์โปรเจกต์นี้ (`commision`)
4. หากโปรแกรมขึ้นเตือนว่า "This directory does not appear to be a Git repository", ให้คลิกที่ลิงก์ **create a repository**
5. ตั้งชื่อ Repository เช่น `real-estate-commission-calc` แล้วกด **Create Repository**

### ขั้นตอนที่ 2: Publish ขึ้น GitHub
1. กดปุ่ม **Publish repository** ที่แถบด้านบน
2. หากต้องการให้ทุกคนเปิดดูหน้าเว็บได้ ให้ **ติ๊กเครื่องหมายถูกออกจาก Keep this code private** (เพื่อให้เป็น Public)
3. กดปุ่ม **Publish repository** เพื่ออัปโหลดขึ้น GitHub

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages (เพื่อให้ได้ลิงก์เว็บไซต์ใช้งานจริงฟรี)
1. ไปที่หน้า Repository ของคุณบนเว็บไซต์ [GitHub.com](https://github.com)
2. คลิกที่แท็บ **Settings** (รูปเฟืองด้านบน)
3. เมนูด้านซ้ายเลือก **Pages** (ใต้หัวข้อ Code and automation)
4. ในส่วน **Build and deployment** $\rightarrow$ **Source**:
   - เลือก **Deploy from a branch**
   - ในช่อง Branch ให้เลือก **`main`** (หรือ `master`) และโฟลเดอร์เป็น **`/(root)`**
5. กดปุ่ม **Save**
6. รอประมาณ 1-2 นาที คุณจะได้รับ URL สำหรับเข้าใช้งาน เช่น:
   `https://<your-username>.github.io/<repository-name>/`
   สามารถนำลิงก์นี้ไปเปิดใช้งานบนมือถือ แท็บเล็ต หรือส่งให้ทีมงานใช้ได้ทันที!
