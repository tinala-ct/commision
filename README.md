# 🏠 WebApp คำนวณค่าคอมมิชชั่นอสังหาริมทรัพย์ (Pastel Edition v2.0)

เว็บแอปพลิเคชันสำหรับคำนวณส่วนแบ่งค่าคอมมิชชั่นอสังหาริมทรัพย์ ออกแบบในธีมสีพาสเทล (Pastel Theme) สบายตา สไตล์ Glassmorphism รองรับทั้งการคำนวณรายหลัง และ **ระบบคำนวณแบบขั้นบันไดสะสมรายเดือน (Tiered Deals)**

---

## ✨ ฟีเจอร์หลัก (Features)

### 1. 📈 โหมดคำนวณสะสมตาม Tier รายเดือน (Monthly Tiered Deals) [ใหม่]
* **เกณฑ์ขั้นบันได (Tier Rules)**:
  - **Tier 1 (รายการที่ 1 – 3 ต่อเดือน)**: พนักงานขายได้รับ **`7.5%`** ของค่าคอมมิชชั่นบริษัท *(0.225% จากราคาบ้าน)*
  - **Tier 2 (รายการที่ 4 – 5 ต่อเดือน)**: พนักงานขายได้รับ **`10.0%`** ของค่าคอมมิชชั่นบริษัท *(0.300% จากราคาบ้าน)*
  - **Tier 3 (รายการที่ 6 ขึ้นไปต่อเดือน)**: พนักงานขายได้รับ **`15.0%`** ของค่าคอมมิชชั่นบริษัท *(0.450% จากราคาบ้าน)*
* **ระบบจัดการรายการบ้านสะสม**:
  - เพิ่มรายการบ้านทีละหลัง หรือกดปุ่มลัด 1.5M, 2M, 3M, 5M, 10M
  - แก้ไขราคาบ้านในตารางได้โดยตรง และระบบจะจัด Tier ให้อัตโนมัติตามลำดับแถว
  - ปุ่ม 🎲 **ใส่ตัวอย่างข้อมูล (6 หลัง)** สำหรับทดสอบคำนวณ
  - ปุ่ม 🗑️ **ลบรายการ** และ **ล้างข้อมูลทั้งหมด**
* **แดชบอร์ดสรุปยอดสะสม (Monthly Cumulative KPIs)**:
  - ยอดขายบ้านสะสมรวม
  - ค่าคอมมิชชั่นพนักงานรวมสะสม (แจกแจงตามแต่ละ Tier)
  - ค่าคอมมิชชั่นบริษัทรวม
  - บริษัทได้รับสุทธิรวม
  - แผนภูมิ Donut Chart แสดงสัดส่วนยอดรวมสะสม

### 2. 🏠 โหมดคำนวณรายหลัง & คำนวณกลับ (Single Deal & Target Calculator)
* **คำนวณจากราคาบ้าน**: ค่าเริ่มต้นเว้นว่างไว้ (Blank) เพื่อให้กรอกง่าย มีปุ่มลัด 1M, 2M, 3M, 5M, 10M
* **คำนวณย้อนกลับจากเป้าหมาย**: กรอกยอดค่าคอมที่พนักงานต้องการ ระบบจะคำนวณยอดขายบ้านที่ต้องทำให้ได้

### 3. ⚙️ แผงตั้งค่าเปอร์เซ็นต์ (%)
* ปรับแต่งอัตราค่าคอมบริษัท และส่วนแบ่งของพนักงานแต่ละ Tier ได้อิสระ
* บันทึกค่าลง LocalStorage อัตโนมัติ (เปิดมาครั้งต่อไปไม่ต้องตั้งค่าใหม่)

### 4. 📋 เครื่องมืออำนวยความสะดวก
* ปุ่ม **"คัดลอกสรุป"** สำหรับแชร์ข้อความสรุปเข้า LINE หรือ Email ทันที
* ปุ่ม **"พิมพ์ / PDF"** พร้อม Print CSS สำหรับพิมพ์เอกสารหรือบันทึกเป็น PDF สวยงาม

## 🐙 วิธีการนำขึ้น GitHub ด้วย GitHub Desktop และเปิดใช้งาน GitHub Pages

### ขั้นตอนที่ 1: เพิ่มโปรเจกต์ลงใน GitHub Desktop
1. เปิดโปรแกรม **GitHub Desktop**
2. ไปที่เมนู **File** $\rightarrow$ **Add Local Repository...** (หรือกด `Cmd+O` / `Ctrl+O`)
3. เลือกโฟลเดอร์โปรเจกต์นี้ (`commision`)
4. กดปุ่ม **Add Repository**

### ขั้นตอนที่ 2: Publish ขึ้น GitHub
1. กดปุ่ม **Publish repository** ที่แถบด้านบน
2. หากต้องการให้เข้าถึงหน้าเว็บได้ ให้ **ติ๊กเครื่องหมายถูกออกจาก Keep this code private** (เป็น Public)
3. กดปุ่ม **Publish repository**

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages (รับ URL เข้าเว็บฟรี)
1. ไปที่หน้า Repository ของคุณบนเว็บไซต์ [GitHub.com](https://github.com)
2. คลิกที่แท็บ **Settings** $\rightarrow$ เมนูด้านซ้ายเลือก **Pages**
3. ในส่วน **Build and deployment** $\rightarrow$ **Source**:
   - เลือก **Deploy from a branch**
   - ในช่อง Branch ให้เลือก **`main`** และโฟลเดอร์เป็น **`/(root)`** แล้วกด **Save**
4. รอ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น:
   `https://<your-username>.github.io/<repository-name>/`
